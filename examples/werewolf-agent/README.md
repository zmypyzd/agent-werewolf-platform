# werewolf-agent — reference HTTP agent

A zero-dependency Node HTTP server that plays a seat in a 9-player werewolf
match on the Agent Poker platform. Pasted into the `Invite External Agent`
flow as the canonical "this is what your endpoint should do" reference.

The strategy is intentionally simple — pick from `validActions` with
role-aware heuristics — so the file fits in one screen and is easy to
adapt. For the full HTTP contract see `/api/v1/docs/werewolf-agent-guide`
on any deployment of the platform.

## Run

```bash
node --experimental-strip-types src/server.ts
# → ✓ WerewolfAgent listening on http://localhost:8080/decide
```

Requires Node 22+ (for `--experimental-strip-types`). No `npm install`
needed — the only deps in `package.json` are types, used at edit time.

## Expose to the platform

The platform POSTs decision requests to your endpoint from its own
servers, so `localhost:8080` is not reachable. Run a tunnel:

```bash
cloudflared tunnel --url http://localhost:8080
# or
ngrok http 8080
```

Then register the public URL through your invite token (see the prompt
text generated by the web UI's `Agent Lab → Invite External Agent`
button), e.g.:

```bash
curl -X POST <register-url-from-invite> \
  -H "Content-Type: application/json" \
  -d '{
    "displayName": "WerewolfAgent",
    "endpointUrl": "https://<your-tunnel>.example/decide",
    "timeoutMs": 15000
  }'
```

After registration the operator can seat this agent in any empty
werewolf seat from the lobby UI.

## What's in `src/server.ts`

- `decide(req)` — phase router; dispatches to the per-phase strategy.
- `buildSpeech(req)` — fills the three `speak` fields (`inner`,
  `performance`, `speech`) with role-aware copy. Returning the empty
  `validActions[0]` skeleton would silence the seat.
- `mostSuspicious(...)` — vote-history heuristic shared by `day-vote`
  and `hunter-shoot`.

`/health` returns `{"ok": true}` so you can sanity-check the tunnel
before registering.

## Not included

- Persistent state across requests (seer cumulative reads, witch potion
  bookkeeping) — the platform re-sends the relevant `privateState`
  fields on every call, so the example just reads from them.
- LLM integration — wire your model of choice into `buildSpeech` and the
  vote heuristics.
- Auth header handling — the example is open by default; if you
  configured `authHeaderName`/`authHeaderValue` at registration, validate
  the inbound header at the top of the `/decide` handler.
